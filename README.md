# 📊 People Analytics: Employee Attrition & Workforce Insights

## 📌 Overview

This project analyzes employee data to understand workforce trends, employee attrition, and key factors influencing retention.
The goal is to provide data-driven insights that can support HR decision-making and improve employee engagement.

---

## 🎯 Objectives

* Analyze employee demographics and distribution
* Identify attrition patterns
* Understand factors affecting employee retention
* Provide actionable HR insights

---

## 📂 Dataset

The dataset includes employee-related information such as:

* Age
* Department
* Job role
* Salary
* Years at company
* Attrition status

---

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib / Seaborn
* Jupyter Notebook

---

## 🔍 Key Analysis Steps

### 1. Data Exploration

* Checked data structure and types
* Identified missing values
* Reviewed key variables

### 2. Data Cleaning

* Handled missing or inconsistent data
* Standardized column formats
* Prepared dataset for analysis

### 3. Exploratory Data Analysis (EDA)

* Employee distribution by department and role
* Attrition rate analysis
* Salary and experience trends
* Age distribution and workforce structure

### 4. Attrition Analysis

* Compared attrition vs non-attrition employees
* Identified high-risk groups
* Analyzed impact of:

  * Salary
  * Tenure
  * Job role

---

## 📊 Key Insights

* Certain roles show higher attrition rates
* Employees with shorter tenure are more likely to leave
* Salary level influences retention
* Workforce distribution is uneven across departments

---

## 📈 Business Recommendations

* Improve retention strategies for high-risk roles
* Review compensation structure
* Focus on employee engagement for new hires
* Implement targeted HR interventions
